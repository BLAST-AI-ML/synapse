# Synergistic Software Platform for AI, Physics Simulations, and Experiments (Synapse)

Synapse is documented in `docs/`.
Start with the [overview](docs/source/overview.md) and [getting started](docs/source/getting-started.md).
The guides that follow cover the [dashboard](docs/source/dashboard.md), the [data model](docs/source/data-model.md), [experiment configuration](docs/source/experiment-configuration.md), [simulations](docs/source/simulations.md), and [ML training](docs/source/ml-training.md).
See [deployment](docs/source/deployment.md) for running Synapse on NERSC services and [developer notes](docs/source/developer-notes.md) for contributing to it.
